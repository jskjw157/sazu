# 예시와 검증 기록

- [examples/saju_db_examples.json](examples/saju_db_examples.json): 자료 작성/검수에 쓸 수 있는 **가상·초안 항목**. 통과된 계산 원천이 아님.
- [verification/saju_source_verification_20261020.json](verification/saju_source_verification_20261020.json): 2026-10-20 당시 일부 엔진의 결과·경계 비교 이력. 비교 대상·버전·전제는 각 항목 확인.

**주의:** 이 디렉터리는 공식 달력 DB 전체를 제공하지 않습니다. 상용 서비스에 넣기 전에 승인된 원천, 고정 계산 정책, 테스트 기대값을 독립적으로 마련해야 합니다.
