# JPL EOP2: 현대 절기 20건 천구극 오프셋 연구 (2026-10-23)

연구 증거이며 운영 승인 아님. EOP2 dX/dY는 IAU 2006/2000A 기준 CIP 좌표 오프셋이지 Horizons IAU76/80의 황경 직접 보정값이 아니다.

## 원천·시간 정의

- 2026-10-22 고정 보관판: https://eop2-external.jpl.nasa.gov/eop2/261022_180002-marge_eop2.long
- SHA-256 ec0077f51f1cc7705265940f9dea7426996d38c06fd13f811e459eecb31d4525
- 원문 헤더: EOP2PNM = IAU 2006/2000A, EOP2TRF = ITRF2008, EOP2CRF = ICRF2; 첫 열은 MJD (TAI), dX/dY 단위는 mas.
- 1962-01-20 ~ 2027-01-18, 23,740개 연속 일별 행. 원문 전체는 Git에 업로드하거나 공개 아티팩트로 재배포하지 않음.
- 기존 절기 TT 사건을 MJD(TAI)로 바꾸는 방법: MJD(TAI) = JD(TT) - 2400000.5 - 32.184/86400. 연속된 두 행의 dX/dY는 연구 목적으로만 선형 보간; JPL이 동일한 보간을 한다고 주장하지 않음.
- 20개 키/원문 해시/일별 누락·중복/날짜 라벨 일치/모델 식별을 실패 우선으로 검증.
- [실제 CI](https://github.com/jskjw157/sazu/actions/runs/39921182783)와 이후 재검증에서 오프라인 Python 테스트 및 원천 SHA 검증·20건 계산을 실행.

첫 11건의 0은 원천 필드의 숫자 0을 뜻할 뿐 그 시대의 실제 천구극 편차가 물리적으로 0임을 입증하지 않는다. 1999년 이후 9건의 dX/dY가 0이 아닌 것으로 기록돼 있다. 최대 절댓값: dX 0.46075mas, dY 0.21895mas.

이전 JPL Horizons quantity31 vs Skyfield IAU2000B 겉보기 황경 차이는 46~50mas였다. 모델 차이와 EOP 보정을 분리하기 전에는 EOP2의 0.4mas 필드 값을 구형 76/80 황경의 47mas 차이에 임의로 더하거나 빼면 안 된다. KASI의 20개 분표 차이도 이를 근거로 해결했다고 집계하지 않는다.

## 정확도 승인과 후속 작업

1. 실제 JPL EOP2의 MJD(TAI)·모델·원천 해시 검사까지 완료했다. 결측/오래된 자료, 시간척도 오해, 무단 새로운 해시 채택은 차단한다.
2. 동일 모델 비교에 필요한 것은 JPL Horizons 조회 때 표기한 EOP 스냅샷(eop.261022.p270118), IAU76/80 기준 원점 및 천구극 보정, 조명/광행차/중력편향 일치 조건이다. JPL 기술 문의에 해당 변환과 스냅샷 제공 조건을 문의한 상태다.
3. IERS/USNO는 dX/dY와 dPsi/dEps 변환을 안내하지만 IAU2006/00A 값을 구 76/80 관례의 황경에 단순 가산할 수 없다.
4. 본 실험 결과는 항상 research_only=true, production_authorized=false. 기존 원래 314건 중 **수정 25건 / 미해결·검증 차단 289건** 유지. 새 수치 해결로 계산한 항목 0건.
5. 외부 천문 API는 연구·사전 검증에서만 호출하며 실제 사주 계산은 외부 상용 운세 API 없이 Python + Express 자체 서비스로 유지한다.
