# ADR-0001 — 상용 운세 API 없이 자체 계산 기반 구축

작성일: 2026-10-21  
상태: **사용자가 확정한 방향 기록**. 세부 설계·구현·출시 검수의 승인을 대신하지 않는다.

## 1. 확정된 사용자 요구

- 상용 사주·만세력·궁합·운세 API를 사용하지 않는다.
- 개발공수 절약이나 임의 출시일보다 완성도와 검증 가능성을 우선한다.
- 이미 검토한 오픈소스를 역할에 맞게 활용하고, 필요한 부분만 직접 구현한다.
- 기준 저장소는 `jskjw157/sazu`다. 이전 조사 자료와 검증 표본을 보존한다.

따라서 과거 조사보고서에 적힌 SAZU·운세위키 등의 도입/유료 비교 시험 제안은 **현재 실행 범위에서 제외**한다. 원래 보고서는 조사 당시 기록으로 유지한다. 이를 삭제하거나 당시 조사 내용을 승인된 현재 계획처럼 고쳐 쓰지 않는다.

## 2. 금지·허용 범위

| 구분 | 결정 |
|---|---|
| 상용 운세 API의 운영 호출 | 사용하지 않음 |
| 상용 운세 API의 시험·비교·장애 대체 호출 | 사용하지 않음 |
| 타사 운세 문구·결과 DB 구매 | 현재 범위에서 제외 |
| 무료 공식 공공데이터 API | 허용된 자료 수집·독립 대조용 후보. 사용자 요청 경로의 필수 외부 의존성으로 만들지 않음 |
| 공개 천문력·시간대 데이터 | 개별 조건·버전·무결성을 확인한 후 로컬 사용 |
| 우리 서버의 자체 HTTP API | 허용. 상용 공급자 API 구매와 다른 개념 |
| 일반 LLM·결제·인프라 공급자 | 이번 결정은 사주·운세 원천에 한정. 이 문서에서 선택·계약·키 발급하지 않음 |

공식 API 인증키가 없거나 자료 권한이 미확정이어도 상용 API를 대체재로 붙이지 않는다. 해당 검증·자료 범위를 명시적으로 미완료로 남기고 독립적으로 가능한 작업을 진행한다.

## 3. 구조 원칙

**원천 → 정규화 → 검증된 데이터 배포본 → 결정론 계산 규칙 → 근거 있는 해석 → 캐릭터 표현**을 분리한다.

- 한국 음력 변환: usingsky 계열을 제한된 어댑터 뒤에서 평가한다. 한국천문연구원 공식 인증 제품이라고 부르지 않는다.
- 절기: Skyfield와 고정 JPL 천문력으로 생성하고 기준 자료와 비교한다. 계산 출력 자릿수를 물리적 정확도로 표현하지 않는다.
- 시간대: 실제 사용한 IANA tzdb 파일과 로딩 경로를 고정한다. 패키지 버전만 기록하고 OS 시간대를 사용하는 상태를 허용하지 않는다.
- 명리: 천문·역법 값과 입춘·절입·자시·대운 등의 관례를 분리해 버전 관리한다.
- 해석: LLM이 팔자를 계산하거나, 해석 추정을 사용자 사실로 저장하지 않는다.

이는 구성 방향이다. 선택 후보의 특정 버전을 운영 승인했다는 뜻은 아니다.

## 4. 완성도의 정의

기능 개수나 테스트 건수만으로 완료를 판단하지 않는다. 다음 증거를 요구한다.

1. 동일한 입력·정책·데이터·코드 버전에서 결과가 재현된다.
2. 한국 음양력, 절입, 과거 시간대, 누락/중복 시각과 입력 불확실성이 설명 가능하다.
3. 원천·코드·라이선스·검증 결과가 배포본에서 역추적된다.
4. 독립 기준 대조와 같은 엔진 내부 왕복 시험을 구분한다.
5. 검증되지 않은 자료·관례·해석이 운영 응답에 조용히 섞이지 않는다.
6. 새 버전의 차이, 실패·복구·롤백·삭제 경로가 시험된다.

완성도를 높이기 위해 단계별로 구현한다. 단계 분리는 기능을 영구적으로 포기하거나 개발비를 줄이려는 결정이 아니다. 대운·용신·격국·궁합은 각각 관례·근거·검증 기준을 갖춘 후 별도 모듈로 확장한다.

## 5. 현재 상태와 문서 우선순위

이번 방향 확정 시 확인한 `main`은 `60bdd8f01a1889f586dc5b39b6c46a59c9fbef5c`이며 연구·설계 자료 11개만 있다. 실행 가능한 계산 서비스·스키마 migration·CI 시험은 아직 없다.

우선순위는 사용자 지시 → 이 결정 기록 → 승인된 상세 설계/구현 계획 → 과거 조사자료 순이다. 과거 자료의 임시 일정이나 상용 API 검토는 현재 의사결정을 덮어쓰지 않는다.
