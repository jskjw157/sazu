## 원본과 샘플 구분

- `data/examples/`: 프로덕션 원천이 아닌 **조건·원고·검수의 작성 예제**.
- `data/verification/`: 연구 당시 고정 버전에서 실행한 **표본 검증 기록**. 전체 범위 인증/정확도 보장 아님.
- KASI의 24기 전체 TXT, 천문력 바이너리, 대량 변환표 등은 미업로드. **원본의 재배포 허용여부와 라이선스가 확정되기 전에는 Git에 추가하지 않습니다.**
- 미래나 연애 결과에 대한 과학적 예측 타당성을 입증한 자료는 없습니다.

## 다음에 확정해야 할 결정

1. 지원 출생연도·출생지역·음양력·시간 미상의 범위.
2. 입춘/12절/일주 경계/자시/시각 보정/대운 관례 및 버전.
3. KASI 원본 이용허락·대량 수집·캐시·재배포 조건.
4. 정밀 절기 시각·출생지 시간대·태양시 보정 검증.
5. 원고 근거검수와 운세 과장·확정 표현 제한.
6. 상용 API 공급자와의 계약, 또는 자체 계산기 개발/테스트 책임자.
